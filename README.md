# ListingReady

小宋1021队的 AI+跨境黑客松首版演示项目。

方向：AI智能上新。  
首版范围：折叠式铝合金手机支架 → Amazon 美国站 Listing。

## 当前版本

- 输入中文商品图片和参数
- 生成英文标题、五点描述、详情描述、搜索词
- 做发布前质检：事实一致性、夸张宣传、待确认字段
- 复制文案或下载 JSON 上新包
- 暂用固定 Mock，等拿到百炼 API Key 后再接真实模型

## 运行

```bash
npm install
npm run dev
npm test
```

## 参赛提交口径

ListingReady 帮跨境卖家把中文商品资料转成可检查、可追溯的海外站点上新包。首版聚焦 Amazon 美国站，避免直接“翻译即发布”的风险，先提取商品事实，再生成本地化 Listing，最后提示卖家确认缺失参数和合规风险。
